# XYRA_LOGIC_LAB

Canonical XYRA research and engineering laboratory for formal reasoning infrastructure.

## Origin

XYRA_LOGIC_LAB is the clean-room reboot and institutional successor to the historical
`XYRA_Logic_Machine` project.

The historical source has not yet been recovered. It is believed potentially to exist
on an external Chromebook. Its absence does not block the reboot, but its provenance
must remain recorded.

## Mission

Develop deterministic logic capabilities that can evaluate formal reasoning structure
without claiming factual truth merely because an argument is logically valid.

Core architectural separation:

LLM / AIR-001
    proposes reasoning, hypotheses, and tool plans

XYRA LOGIC BACKBONE
    checks formal validity, contradiction, derivability, and reasoning type

EVIDENCE SYSTEM
    determines whether premises are supported

COACH / APPLICATION
    explains results

HUMAN
    retains final decision authority

## Current Status

BASELINE ESTABLISHMENT ONLY.

No production logic capability is represented by the founding repository.
